# SOMA//MASSILIA - La Chair sous Licence

Vertical Slice 0.1.0 jouable, reconstruite en code et assets originaux pour le depot public `darknigthmare/soma-massilia`.

## Contenu jouable

- Néo-Massilia, 2197, prologue `La Dette de Chair`.
- Environnements 3D raycastes avec personnages 2D orientes en huit directions.
- Trois corps loues: MISTRAL-3, MÔLE-9, SIBYLLE-6.
- Modes Chair, Cortex, Spectre et Syndicat.
- Armes: pistolet, mitraillette, fusil, lame; munitions, rechargement, recul, blindage.
- Ennemis: gardes, lourds, drones, Le Collecteur avec transferts de conscience.
- Piratage jouable, impulsion cybermancienne, charge neurale, Nara Velvet recrutee.
- Station Zéro avec six installations ameliorables et operations de Syndicat.
- Sauvegarde locale, migrations, export/import JSON, audio WebAudio, accessibilite, PWA/offline.

## Commandes

```bash
npm run dev
npm run lint
npm run test
npm run build
```
